Tab Flash Jump Hints

This local MVP keeps Chrome tab titles clean by default. When the matching Karabiner rule and helper are installed, hold physical left Ctrl while Chrome is frontmost to show temporary one-key title/favicon hints, tap the visible label to jump, and release Ctrl to hide.

Label order

    Popup fallback

    The Ctrl-hold pilot jumps only one-key labels. Use the extension popup for overflow/two-key labels such as aa, for restricted pages, or whenever the local helper is not available.

    Setup gate

    The helper uses Chrome JavaScript from Apple Events. If chrome-tab-prefix-jump doctor asks for setup, open Chrome and enable View > Developer > Allow JavaScript from Apple Events, then rerun the doctor command.

    Tradeoff

    While Chrome is frontmost, exact physical left Ctrl plus one of the label keys is reserved for tab jumps. If that conflicts with text-editing habits, change the Karabiner rule to another hold key or remove the rule.

Tab Flash Jump Hints

This local MVP keeps Chrome tab titles clean by default. When the Hammerspoon loader and Chrome-scoped Karabiner bridge are installed, press Hyper+K while Chrome is frontmost to show subtle one-key overlay labels near the tab strip, then tap the visible label to jump.

Label order

    Popup fallback

    The Hyper+K modal jumps only one-key labels. Use the extension popup for overflow/two-key labels such as aa or whenever the Hammerspoon helper is not available.

    Setup gate

    The resident Hammerspoon overlay reads Chrome tabs and switches the active tab without rewriting page titles. The legacy chrome-tab-prefix-jump doctor command is still available for fallback diagnosis and may ask for Chrome’s View > Developer > Allow JavaScript from Apple Events setting.

    Tradeoff

    While Chrome is frontmost, Hyper+K is reserved for the tab-jump modal instead of the global Hyper+K up-arrow mapping. If that conflicts with navigation habits, remove the Chrome-scoped Karabiner bridge.

Tab Flash Jump Hints

This local MVP keeps current-window tabs labeled with always-on, home-row-first title prefixes. The extension popup remains as an optional helper list, but the test is simply whether visible prefixes make tab scanning easier.

Label order

    Limits

    Chrome extensions cannot draw over Chrome’s native tab strip or listen for raw “hold Cmd” key-up/key-down events. This MVP intentionally avoids that path and uses supported extension surfaces: always-on title prefixes, favicon badges, and the action popup.
